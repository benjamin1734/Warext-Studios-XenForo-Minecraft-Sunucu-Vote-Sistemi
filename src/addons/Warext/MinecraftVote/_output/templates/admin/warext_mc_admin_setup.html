Kurulum ve Yapılandırma
Bu sayfa eklentiyi ilk kez kuran yöneticiler için başlangıç merkezidir. Minecraft kategorileri XenForo forum kategorilerine bağlı değildir; sunucu listesindeki filtreleme ve sınıflandırma etiketleridir.

1. Genel Ayarlar

Admin CP → Setup → Options bölümünde Warext Minecraft Sunucu & Vote seçenek grubunu açın. Oy bekleme süresi, CAPTCHA, misafir oyları, doğrulanmış Minecraft hesabı zorunluluğu, NuVotifier retry, sponsor, API ve webhook ayarları burada yönetilir.
JSON API: AçıkKapalı · HTTPS webhook: AçıkKapalı

2. Kullanıcı Grubu İzinleri

Admin CP → Groups & permissions → User group permissions bölümünde Minecraft Sunucu & Vote izin grubunu düzenleyin.
Sunucu ekleyebilir: Kullanıcının yeni Minecraft sunucusu göndermesini sağlar.
Oy verebilir: Aktif sunuculara oy verme yetkisidir.
Değerlendirme yapabilir: Sunuculara puan ve yorum bırakma yetkisidir.
Favorilere ekleyebilir: Favori ve güncelleme bildirimi özelliklerini açar.
Raporlayabilir: Sunucu raporu göndermeyi açar.
Bir kullanıcıda ilgili izin kapalıysa buton görünmez veya işlem reddedilir. Eklentiyi test ederken test hesabının kullanıcı grubuna bu izinleri verdiğinizden emin olun.

3. Kategoriler

Survival, SkyBlock, BoxPvP gibi kategoriler sunucuyu sınıflandırır. Kategori seçimi ek form alanı oluşturmaz ve alan zorunluluğunu değiştirmez. Java/Bedrock alanları sunucu türüne göre anlam kazanır.
Kategorileri Yönet

4. Sunucu Ekleme Akışı

Java: Ana adres ve Java portu kullanılır. Bedrock alanları boş bırakılabilir.
Bedrock: Ana adres sunucunun temel adresidir; Bedrock adresi boş bırakılırsa ana adres kullanılır. Bedrock portunu gerçek portunuza göre ayarlayın.
Crossplay: Java ana adresi ile Bedrock adresi/portu birlikte girilir.
Yeni kayıt önce Onay bekliyor durumuna gelir. Yönetici onayından sonra genel listede görünür ve oy alabilir.
Bekleyen Sunucular Tüm Sunucular

5. NuVotifier ve Oy Teslimatı

Sunucu sahibi, kendi sunucu detay sayfasındaki NuVotifier Ayarları alanından bağlantıyı yapılandırır. Oy kaydı ile oyun içi ödül teslimatı birbirinden ayrıdır; oy önce kaydedilir, ardından teslimat kuyruğu çalışır.
Teslimat sorunlarını Admin CP → Minecraft Sunucu & Vote → Sistem Sağlığı ve Oy Teslimat Kuyruğu ekranlarından takip edebilirsiniz.
