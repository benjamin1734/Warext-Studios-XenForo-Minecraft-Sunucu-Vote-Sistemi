# Warext Studios | XenForo Minecraft Server & Vote System

## English

Warext Studios Minecraft Server & Vote System is a XenForo 2.3 add-on for Minecraft server discovery, listings, secure voting, and server-owner management.

## Installation

Upload `Warext-MinecraftVote-1.1.9.zip` directly through **Admin CP > Add-ons > Install/upgrade from archive** without extracting it. It can be upgraded directly over an existing installation.

After installation, follow **Admin CP > Minecraft Server & Vote System > Installation & Configuration**.

## Features

- Ranked, horizontal, mobile-friendly Minecraft server directory designed for modern vote sites
- Direct Vote and Copy IP actions from the listing
- Directory summary, quick sorting, category chips, and expandable advanced filters
- Modern server profile page with hero area, banner, ranking, quick actions, details, latest voters, top voters, and reviews
- Clean management interface that groups server-owner/staff actions in one place
- Minecraft Servers entry in XenForo Public Navigation
- Add Server and My Servers management pages
- Java, Bedrock, and Crossplay server listings
- Ping, uptime, ranking, and analytics
- Secure voting, CAPTCHA, and Minecraft account verification
- Modern vote page combining server profile data, banner, live metrics, and the voting panel
- NuVotifier v2 integration with queue and retry support
- Server ownership and team management
- Seasons, streaks, achievements, reviews, and favorites
- Moderation, reporting, audit, and system-health tools
- Automatic 468×60 static banner, optimized 468×60 GIF banner, 1200×400 detail cover, and trailer support
- Automatic crop, resize, compression, and WebP conversion for static images when appropriate
- Two-way connection between forum promotion threads and vote records
- Optional automatic vote-listing creation when a thread is posted in configured forum categories
- Moderator approval through XenForo's built-in Approval Queue
- Sponsored listings
- JSON API, HTTPS/HMAC webhook support, and sitemap integration

## Versioning

After patch version 9, the minor version is incremented: `1.0.9 → 1.1.0`, followed by `1.1.1` ... `1.1.9 → 1.2.0`.
