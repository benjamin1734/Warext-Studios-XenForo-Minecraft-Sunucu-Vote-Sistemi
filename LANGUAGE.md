# Language support / Dil desteği

Minecraft Server & Vote System uses XenForo's native Phrase/Language system.

- `languages/Turkish.xml`
- `languages/English.xml`

Import the matching XML into an existing XenForo language or into a child language based on it. Visitors use XenForo's normal language selector; the add-on follows that selection automatically.

Server names, descriptions, update posts, reviews, moderation notes and other user/staff-generated content are not automatically translated. Interface labels, buttons, statuses, settings, validation messages and ACP screens are translated.

Yeni kullanıcıya görünen sabit metinler XenForo phrase sistemi kullanılmadan PHP/template/JS içine eklenmemelidir.
